# Weapon Test

Every weapon base and pickup in the map holds the weapon chosen in the mutator's settings. Similarly, every ammo pickup becomes the chosen weapon's ammo. Weapon lockers are switched off, though.

Spawn weapons are unchanged because there ain't no reason to mess with that. For now...

Type `mutate idlebots` in the console (or bind it to a key) to toggle idle bots. They end up more *stuck* than idle, but either way become useless target dummies.

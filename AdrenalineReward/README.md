# Adrenaline Reward

Adrenaline is thrown from a fragged player's body like Sonic the Hedgehog rings. These new pickups hang around for a bit and then disappear similar to a dropped weapon.

These settings can be configured:

- **Pickup value:** Adrenaline granted per pickup, 1-10, for both those placed in the map and thrown pickups. Stock is 2; UT2003 did 3. I like it at 5, personally, but that's because I'm using another mutator that resets your adrenaline count on death.
- **Percent thrown:** How much of a fragged player's adrenaline is thrown, 10-100%. Default is 100.
- **Keep unthrown:** The fragged player keeps the adrenaline that isn't thrown instead of losing it. Off by default.
- **Lifespan:** Seconds thrown pickups stay after landing before fading out. Default is 8 and matches that of dropped weapons.
